# Stellar Burgers: Автоматизированное тестирование

Этот проект содержит набор автоматизированных тестов для веб-приложения Stellar Burgers, разработанных с использованием Selenium и Pytest.

## Описание

Тесты проверяют различные аспекты функциональности приложения, включая:

* *Регистрацию:* корректность регистрации новых пользователей, валидацию полей ввода, обработку ошибок.
* *Авторизацию:* вход пользователей с главной страницы, из личного кабинета, формы регистрации и формы восстановления пароля.
* *Личный кабинет:* доступ к личному кабинету, выход из аккаунта.
* *Навигацию:* переход по страницам приложения, клик по логотипу для возврата на главную страницу.
* *Вкладки ингредиентов:* проверка скролла при клике на вкладки "Булки", "Соусы" и "Начинки".

## Технологии

* *Python:* Язык программирования для написания тестов.
* *Pytest:* Фреймворк для запуска и организации тестов.
* *Selenium:* Библиотека для автоматизации взаимодействия с веб-браузером.
* *WebDriver:* Для управления браузером (в данном случае, ChromeDriver).

## Запуск тестов

1. Убедитесь, что у вас установлен Python 3.12.
2. Установите необходимые библиотеки:
pip install pytest selenium
3. Скачайте ChromeDriver, соответствующий версии вашего браузера Chrome, и добавьте его в `PATH`.
4. Перейдите в директорию проекта в терминале.
5. Запустите тесты командой:
pytest

## Структура проекта

* *`locators.py`:* Содержит классы с локаторами элементов веб-страниц.
* *`test_*.py`:* Файлы с тестами.

## Дополнительная информация

* *Page Object Model (POM):* Проект может быть расширен с использованием POM для улучшения организации и maintainability кода.
* *Data-driven testing:* Тесты могут быть параметризованы для проверки различных входных данных.
* *Reporting:* Интеграция с инструментами отчетности, такими как Allure, может улучшить визуализацию результатов тестирования.
